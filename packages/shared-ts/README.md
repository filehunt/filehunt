# @filehunt/shared-ts

Shared TypeScript utilities for Filehunt.

## Installation

```bash
npm install @filehunt/shared-ts
```

## Usage

```typescript
import { helloWorld, greet } from '@filehunt/shared-ts';

console.log(helloWorld()); // "Hello World from shared-ts!"
console.log(greet('Alice')); // "Hello Alice from shared-ts!"
```

## Development

```bash
# Install dependencies
npm install

# Type check
npm run type-check

# Build
npm run build

# Watch mode
npm run dev
```
